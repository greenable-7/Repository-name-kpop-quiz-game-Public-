# K-pop 퀴즈 게임

## 프로젝트 개요

터미널에서 즐기는 K-pop 상식 퀴즈 게임입니다. 문제를 풀고, 나만의 문제를 추가하며, 최고 점수를 저장할 수 있습니다.

## 퀴즈 주제와 선정 이유

K-pop은 다양한 그룹과 음악을 통해 친숙하게 접할 수 있는 주제입니다. 좋아하는 아티스트에 관한 문제를 직접 만들고 친구와 함께 풀 수 있도록 K-pop을 주제로 선택했습니다.

## 실행 방법

Python 3.10 이상이 필요하며, 외부 라이브러리는 사용하지 않습니다.

```bash
cd kpop-quiz-game
python3 main.py
```

## 기능 목록

- 퀴즈 풀기: 등록된 모든 문제를 풀고 점수와 정답 여부를 확인합니다.
- 퀴즈 추가: 문제, 선택지 4개, 정답 번호를 입력하여 새 퀴즈를 저장합니다.
- 퀴즈 목록: 등록된 문제를 번호와 함께 확인합니다.
- 점수 확인: 지금까지 기록된 최고 점수를 확인합니다.
- 안전한 입력 처리: 빈 입력, 문자, 범위를 벗어난 숫자, Ctrl+C 및 EOF를 처리합니다.
- 데이터 복구: `state.json`이 없거나 손상되어도 기본 퀴즈로 시작합니다.

## 파일 구조

```text
kpop-quiz-game/
├── main.py          # 프로그램 시작과 메뉴 흐름
├── game.py          # QuizGame 클래스와 게임 기능
├── quiz.py          # Quiz 클래스
├── default_data.py  # 기본 K-pop 퀴즈 5개
├── state.json       # 실행 중 생성되는 저장 데이터
├── README.md
└── .gitignore
```

## 데이터 파일 설명

프로젝트 루트의 `state.json`은 UTF-8 JSON 형식으로 퀴즈와 최고 점수를 저장합니다. 처음 실행하거나 파일이 손상된 경우에는 기본 퀴즈를 사용합니다.

```json
{
  "quizzes": [
    {
      "question": "문제 내용",
      "choices": ["선택지 1", "선택지 2", "선택지 3", "선택지 4"],
      "answer": 1
    }
  ],
  "best_score": 80
}
```
